## What

On `#/repo/alpha`, each session card shows its transcript path in a `code.transcript` that is
`overflow-x: auto; white-space: nowrap` (`src/views/repo/RepoSessions.vue`). The paths are longer
than the card, so the element scrolls, but it holds no focusable element and has no `tabindex`:
a keyboard user cannot scroll it and never reads the end of the path. axe-core reports
`scrollable-region-focusable` (WCAG 2.1.1, serious) in both themes at both gating viewports.

The copy button beside it copies the full path, so the value is reachable; reading it is not.

## Why S2

Hard gate 5 fails; the task (read the path) has a workaround (copy), so it is not S1.

## Fix (one line)

Give the scroll region `tabindex="0"` and an accessible name, or wrap the path instead of
scrolling it. Cost S.
