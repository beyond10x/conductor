On the repository page each session card shows its transcript path in `code.transcript`
(src/views/repo/RepoSessions.vue:54), a region that scrolls horizontally when the path is longer
than the card. It holds nothing focusable, so a keyboard user cannot scroll it to read the rest of
the path. axe-core reports it as serious (scrollable-region-focusable) for both sessions of the
fixture, in both themes. The Copy button beside it copies the whole path, so the value is not lost.

Sessions affected: the repository scenario, 1 of 5. Cost: S (make the region focusable with a
name, or wrap the path instead of scrolling it). The baseline holds the 4 nodes under decision R-01.
